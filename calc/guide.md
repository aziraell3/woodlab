# 주먹장 계산기 — 오프라인 HTML 및 에이전트 인수인계 명세

## 1. 산출물

- `jumeokjang_calculator.html`: HTML + CSS + Vanilla JavaScript + SVG를 모두 포함한 단일 파일. **외부 CDN, 폰트, 이미지, npm 의존성 없음.** 브라우저에서 직접 열어 오프라인 사용.
- 본 문서: 에이전트가 기능을 유지·확장할 때 참고할 제품/UI/수학/작도 명세.
- **실제 HTML 화면에 「최종 입력 테두리 기준」과 같은 부연 설명표는 넣지 않음.** 아래 컬러 규칙은 개발 명세일 뿐.

## 2. 기본 UI / 상태

### 공통 입력 (탭 바깥)

| 항목 | 기본값 | 색상 |
|---|---:|---|
| 부재의 가로 `m` (mm) | 132 | 오렌지 |
| 부재의 두께 `h` (mm) | 20 | 오렌지 |
| 기울기 `angle` (°) | 7 | 보라 |
| 방향반전 `reverse` | 미체크 | 보라 |
| 좌/우 기울기 적용 `edge-slope` | 미체크 | 기울기 설정 그룹 |

배치: 부재 가로 한 줄, 부재 두께 한 줄, 그 아래 **기울기 (°) 입력, `방향반전`, `좌/우 기울기 적용` 세 컨트롤을 한 줄에 배치**한다. 유형별 탭 안에는 기울기 적용 체크박스를 중복 배치하지 않는다. A형에서 좌우 촉 옵션이 꺼져 있거나 C형처럼 좌우 촉이 없으면 공통 체크박스는 비활성화(disabled)한다. 또한 A·B형 모두 좌우 촉의 길이가 **0mm이면** 기울기를 적용할 양끝 영역이 없으므로 비활성화한다. A형에서 좌우 촉 옵션을 켜고 길이가 양수이거나 B형에서 길이가 양수일 때 활성화한다.

### A형: 균등 분할

- 촉의 개수 `n=5`, 촉의 가로 길이 기준 `aw=20`을 **한 줄(2열)**에 배치.
- `좌우 촉 길이 별도 지정`: 기본 미체크. 체크 시 좌우 촉 각각 `edge=10`mm 입력 표시.
- 좌/우 촉 기울기 체크박스는 **공통 기울기 영역**에만 존재한다. A형 좌우 촉 옵션을 켜고 길이가 0보다 클 때 활성화한다. **길이 0은 정상 입력**이며 이때 양끝 촉 없이 일반 n분할 작도를 표시한다.

### B형: 좌우 촉 구분

- 촉의 개수 `n=5`와 촉의 길이 `15`mm를 **한 줄(2열)**에 배치.
- 그 아래 좌우 촉 길이 `edge=10`mm를 단독 입력으로 배치. **B형의 촉 사이 간격 입력란은 제거**한다. 중앙 구간은 촉 개수로 균등 분할한다.
- 공통 기울기 영역의 좌/우 촉 기울기 체크박스는 길이 > 0일 때 활성화. **중요: B형의 '촉의 길이'는 현재 입력 가능하지만 대각선 계산에 적용되지 않음.** 임의로 연계했다고 주장하면 안 됨.

### C형: 촉 고정/간격 자동

- 촉의 개수 **기본 3개**, 촉의 가로 길이 `15`mm를 한 줄에 배치.
- 촉 사이 간격 입력란은 **없음**. 가로 방향 간격은 자동 계산.
- C형에는 별도 좌우 촉이 없어 공통 영역의 `좌/우 기울기 적용` 체크박스는 비활성화한다.

### 공통 출력 및 UI

- 대각선 총길이, 대각선 균등 구간(또는 C형 촉/간격), 추가 환산 치수, SVG 작도, 전체 초기화 버튼.
- 작도 표시 선택: **각 구간 표시 / 누적 치수 표시** 2종. '간략 표시' 없음.
- 각 탭의 촉 개수는 독립적 상태이고, 부재의 가로/두께/기울기는 전 탭에서 공유.
- 탭 변경 시 각 탭의 값 유지. 전체 초기화 시 모든 값 및 체크박스 기본값 복구.

## 4. 수학 규칙

공통 기호:

- `m`: 부재의 가로 길이 (실수 가능)
- `h`: 부재 두께
- `n`: 각 타입의 촉 개수 (정수, 1~20; C형 2~20)
- `D`: 파란색 작도 대각선 길이. A·C형은 **정수이며 `D > m`**; B형은 **좌우 촉을 뺀 중앙 대각선**으로서 `D > m-2e`
- `k`: 대각선의 균등 분할 길이, 정수
- 경계의 가로 투영 치수는 소수 허용.
- 목표 비율은 대체로 부재보다 약 10% 긴 대각선(`m * 1.1`). 이는 UI 입력값으로 노출하지 않음.

### A형

```js
k = Math.max(Math.floor(m / n) + 1, Math.ceil(aw), Math.round(m * 1.1 / n));
D = n * k;
```

- 기본 대각선 기준점: `0, k, 2k, ..., nk` (`n`등분).
- 좌우 촉 별도 지정 시에도 **대각선은 n등분**. 길이가 `e=0`인 경우 양끝 영역 2개를 만들지 않고 기본 n구간으로 그린다. 제거·유지 영역 작도만 양끝 2개 구간 추가하여 `n+2`개 영역.
- 현재 구현에서 좌우 촉 별도 지정 시 빨간/초록 경계는 별도 가로 분할 기반이므로 **대각선 n등분의 투영점과 내부 영역 경계가 일치하지 않을 수 있음**. 실측 제작 도면으로 확정하려면 이 부분을 추가 설계해야 함.

### B형 — 좌우 촉을 제외한 중앙 구간만 대각선 작도 (수정 확정)

- 부재 가로 `m`, 좌우 촉 각각 가로 `e`, 촉 개수 `n`.
- 중앙 가로 길이 `w = m - 2e`이며 길이 `e > 0`인 좌우 촉은 유지하되 **파란색 대각선에는 포함하지 않는다**. `e=0`도 허용하며 이 경우 전체 폭 `w=m`을 중앙 구간으로 사용하고 0폭의 끝 촉 영역은 그리지 않는다.
- 중앙 대각선 분할 `k = max(1, floor(w/n)+1, round(w*1.1/n))` (정수).
- **파란 대각선 전체 길이 `D = n*k` (정수)**, 반드시 `D > w`.
- 대각선 시작점은 **왼쪽 초록 촉의 안쪽 경계**(`x=e`), 끝점은 **오른쪽 초록 촉의 안쪽 경계**(`x=m-e`). 부재 바깥 양 끝에서 시작/종료하지 않는다.
- 대각선 표시 눈금은 `0, k, 2k, …, nk`로 **모두 정수**. 좌우 촉의 대각선 환산값, 양 끝의 소수점 구간은 **계산·출력·작도 모두 제거**.
- **B형 작도:** 좌우 초록색 촉의 실제 **가로 길이 `e`**를 해당 초록색 영역 **바로 아래에 초록색 글씨로 각각** 표시한다. 이 값은 파란 대각선 위에는 표시하지 않는다. 주황색 전체 부재 가로 치수선은 이 초록색 숫자보다 아래에 배치하여 겹침을 피한다.
- 예: `m=132`, `e=10`, `n=5` -> 중앙 가로 `w=112`, 정수 분할 `k=25`, **중앙 대각선 `D=125`**. 초록 촉 10mm씩은 대각선 밖에 존재.
- 동일 축척 비율로 화면상 중앙 구간의 대각선 상승폭은 `sqrt(D²-w²)`를 중앙 가로 너비 `w` 기준으로 계산한다. 미리보기에서는 높이를 제한할 수 있다.
- B형의 '촉 사이 간격' 입력은 UI에서 제거되었다. '촉 길이' 입력은 아직 계산과 연결되지 않는다.

### C형

- 입력한 촉의 가로 길이 `t`를 실제 가로 고정값으로 유지.
- 간격은 자동 계산 `g = (m - n*t) / (n-1)`; 필요 조건 `n >= 2`, `n*t < m`.
- 가로 구간: 촉 `t` × `n`개 + 간격 `g` × `(n-1)`개 = `m`. **좌우 잔여 여백 0**.
- `t:g` 비율을 0.001mm 단위 반올림 정수로 환산한 뒤 최대공약수로 약분해 최소 정수 비율 `u:v` 도출.
- `base = n*u + (n-1)*v`, `multiplier = max(1, floor(m/base)+1)`.
- 대각선 촉 길이 `u*multiplier`, 간격 `v*multiplier`, 총길이 `D=base*multiplier` (세 값 모두 정수).
- **주의**: 현재 C형 정수화 비율은 소수 셋째 자리까지 입력값 기준으로 근사. 입력 자릿수가 더 크면 엄밀한 비례와 미세 오차가 생길 수 있음. SVG 분할 기준점은 실제 가로 `t`, `g`의 투영 위치를 사용하며 표시 대각선 간격값과 근소하게 다를 수 있음. 정밀한 제작용에서는 임의 소수 가로를 정확한 유리수로 변환하거나 정수 비율 제약을 사용자에게 알려야 함.
- 예: `m=132`, `t=15`, `n=3` -> 가로 간격 `43.5`; 대각선 촉 `20`, 간격 `58`, 총길이 `176` (최소 정수 조합 10:29에서 대각선이 m보다 커야 하므로 배수 2).

## 5. SVG 작도 규칙

- 부재: 오렌지 외곽선 직사각형, 가로 `m`과 세로 `h` 동일 스케일을 우선 반영; 대각선은 파란 사선.
- 대각선 분할 치수 라벨은 **파란 대각선 위쪽**에 배치.
- 초록색 좌우 촉은 유지 영역; 제거 영역은 빨간 X형 교차 빗금으로 표시한다.
- 모든 구간 왼쪽부터 1부터 번호 매김.
- **A형 좌우 촉 없음(미선택 또는 길이 0)**: 1 유지, 2 제거, 3 유지, ...
- **A형 좌우 촉 길이 양수 또는 B형 촉 길이 양수**: 1번 초록 좌측 촉 유지, 2·4·6... 짝수 영역 제거, 홀수 내부 유지, 마지막 초록 우측 촉 유지. 예: 촉 개수 5이면 시각적 영역 총 7개.
- **B형 촉 길이 0**: 별도 끝 영역 없이 중앙 n개 구간만 그리며 첫 구간부터 제거/유지를 번갈아 표시한다. 대각선은 x=0부터 x=m까지이다.
- **C형**: 촉(유지)와 간격(제거) 번갈아 표시. n개 촉, n-1개 제거 영역.
- 자주색 사선 각도는 중앙선 교점 기준 양쪽으로 `thickness/2 * tan(angle)` 이동하여 표시.
- `방향반전`: 부호를 -1로 반전; 다른 계산 결과는 바꾸지 않음.
- `좌/우 기울기 적용`: **상단 공통 기울기 그룹에 항상 표시**하고, A형의 좌우 촉 별도 지정이 활성화되어 있으면서 길이가 양수이거나, B형에서 좌우 촉 길이가 양수일 때만 사용 가능하도록 한다. C형 및 좌우 촉이 없는 A형에서는 비활성화한다. 기본은 미체크. 체크하면 양끝 촉의 내부 경계에 기울기 사선을 적용.
- SVG 대각선의 시각적 높이는 화면을 위한 상한을 둠. 긴 대각선은 시각적 비율이 축소될 수 있으며, 이 미리보기를 **제작용 절대 축척 도면이라고 해석하면 안 됨**.
- 각 구간 표시 / 누적 표시가 변경되면 **계산값 자체가 아니라 치수 라벨만 변화**.

## 6. 에이전트 구현 / 회귀 점검

1. 파일을 `file://` 로 열고 브라우저 개발자 도구 네트워크에서 외부 요청이 없는지 확인.
2. 각각의 5개 색상 Input에는 회색 기본 테두리나 컬러 배경 없이 **단일 2px 테두리**만 있어야 함.
3. A형 시작 시 좌우 촉 별도 지정 OFF; B형 촉 개수 5; C형 3.
4. 공통 부재 가로를 바꾸고 탭 전환 시 세 탭 모두 변경된 값을 사용해야 함. 탭별 촉 개수는 서로 변경되지 않아야 함.
5. A형 좌우 OFF, 촉 5 -> 구간 5개 및 짝수 제거. A형 좌우 ON에서 길이 0을 입력해도 구간 5개가 정상 작도되어야 함. B형 길이 0에서는 전체 폭 중앙 대각선이 정상 작도되어야 함. A형 좌우 ON -> 구간 7개, 양끝 초록 유지, 2·4·6 제거. 같은 규칙 B형에도 적용.
6. 방향반전을 토글하면 보라색 절단선/제거 영역의 경계 기울기 방향만 반전되고 숫자 D/k가 변하면 안 됨.
7. 좌우 촉 기울기 적용 ON/OFF 시 초록색 끝 경계가 함께 변하는지 확인.
8. B형 132/10/5 -> 중앙 가로 `112`, 파란 대각선 `D=125`, `k=25` × 5 검증. 파란 선은 가로 x=10에서 x=122까지이며 초록 좌우 촉 위에는 파란 대각선·소수점 환산값이 없어야 함.
9. C형에서 촉 길이와 개수를 바꿔도 여백은 항상 0이며, 계산된 대각선 치수는 정수인지 검증.
10. 계산 불가능한 수치에는 에러 메시지를 표시하며 NaN/Infinity SVG 좌표를 출력하지 않아야 함.
11. 전체 초기화 시 색상, A형 좌우 OFF, C형 3개, 보라색 기울기 반전 OFF, 누적 치수 표시 초기화 확인.

## 7. 개선 필요 사항 / 범위 경계

- B형의 '촉 길이' 입력을 실제 절단 구간 산식에 연결하려면 현재 '중앙 n등분' 모델과 어떻게 조합할지 추가 사양 결정 필요. 촉 사이 간격 입력은 불필요하여 제거함.
- C형의 0.001mm 반올림 기반 정수 비율 방식은 대각선이 불필요하게 길어질 수 있음. 정수 분할을 유지하면서 대각선을 10% 근처로 최적화하는 개선 가능.
- A형 끝 촉 활성화 시 파란 대각선 분할 지점과 실제 가로 절단 경계 정합성에 대한 후속 설계 필요.
- 실제 톱날 두께(kerf), 가공 공차, 잔여 강도, 보정치 등은 포함되지 않음.

**위의 개선 필요 항목은 현행 구현에서 이미 해결된 것으로 가정하면 안 됩니다.**

## 8. 반응형 2단 배치 (업데이트)

- **768px 미만**: 기존처럼 공통 입력 → 타입별 입력 → 계산 결과 → 작도의 세로 흐름을 유지.
- **768px 이상**: 화면을 왼쪽 입력 영역(`.workspace-inputs`)과 오른쪽 결과·작도 영역(`.workspace-preview`)으로 2열 배치.
- 오른쪽 영역은 **작도 미리보기를 먼저 표시**, 계산 결과를 그 아래에 표시하여 수치 수정 직후 바로 도형을 확인할 수 있음.
- 오른쪽 `.workspace-preview`는 `position: sticky; top: 16px`으로 스크롤 중에도 상단에 머무름. 미리보기가 화면보다 높으면 `max-height: calc(100vh - 32px); overflow: auto`로 독립 스크롤.
- 768~960px에서는 양쪽 열의 너비를 균등하게 조정하고 패딩을 줄여 입력창이 좁아지지 않도록 처리.
- 반응형 2단 배치는 유지함. 이후 B형 대각선 계산 및 SVG 선의 시작·끝 범위만 사용자 피드백에 따라 수정됨.
- 회귀 테스트: 브라우저 너비 **767px/768px/960px/1280px**에서 입력값 변경 후 도형이 잘 보이는지, 우측 sticky 및 독립 스크롤 동작을 확인.


### 공통 기울기 UI 및 접근성 문구 (2026-11-22 반영)

- 사용자에게 보여주는 설정 라벨은 **`좌/우 기울기 적용`**으로 고정한다. `초록색 좌우 촉`처럼 색상을 유일한 식별 기준으로 쓰는 설명을 설정·입력 영역에 사용하지 않는다.
- 색약·색맹 사용자도 기능을 이해하도록, 항목의 명칭과 상태(체크 여부 및 비활성 여부)로 기능을 구분한다. 색상은 부가적 시각 정보로만 사용한다.
- **작도 아래의 기존 색상 범례(부재, 대각선, 기울기, 좌우 촉, 제거)는 유지**한다.
- 공통 체크박스는 좌우 촉이 없는 타입 또는 촉 길이가 `0mm`인 경우 `disabled`되지만, A형에서 좌우 촉을 다시 켜고 길이를 양수로 바꾸거나 B형에서 길이를 양수로 바꾸면 이전 체크 상태를 복원한다.
